# Cerne Madeireira

Tycoon 3D de madeireira para jogar no celular (Safari/iPhone).

**Jogar:** abra o link do GitHub Pages deste repositório no Safari → Compartilhar → **Adicionar à Tela de Início**. O jogo abre em tela cheia e funciona sem internet.

- A raiz do repositório é o jogo pronto (`index.html`, ícones, manifesto e service worker).
- `codigo/` guarda o código-fonte. Para gerar uma nova versão: `cd codigo && npm install && node build.mjs` e copie o conteúdo de `codigo/site/` para a raiz.
